你这个场景应当做成一个 **“基于三遮罩的智能回贴 / 背景保护合成节点”**，而不是普通 mask blend。

你的遮罩关系可以这样定义：

```text
A   = 图一上手涂的总编辑遮罩
A_P = 图一原人物 / 原物体遮罩
B_P = 替换后新人物 / 新物体遮罩
O   = 原图
E   = 局部编辑后的图 / inpaint 输出图
```

目标是：

```text
能用原图背景的地方尽量用 O
必须用编辑结果的地方用 E
两者之间用距离场 / 羽化 / 颜色匹配自然过渡
```

---

# 一、核心判断逻辑

你说的：

```text
A - (A_P + B_P)
```

确实是一个很重要的安全背景区域，但**不能直接全部硬切回原图**。

原因是：

1. `A_P` 和 `B_P` 的分割边缘通常不准；
2. 新人物 / 物体的阴影、接触边、反光可能在 `B_P` 外；
3. 原人物残留区域可能在 `A_P` 边缘外；
4. 直接硬切会导致人物边缘、脚底、头发边缘出现断层。

所以应该把它拆成三个区域：

```text
1. 编辑核心区：必须用 E
2. 原图安全背景区：必须用 O
3. 过渡区：O 和 E 自然混合
```

---

# 二、推荐遮罩构造

## 1. 先构造物体联合遮罩

```text
U = A_P ∪ B_P
```

也就是：

```python
U = max(A_P, B_P)
```

这个区域代表：

```text
原人物区域 + 新人物区域
```

它们附近都不应该直接使用原图背景。

---

## 2. 编辑核心区 edit_core

```text
edit_core = A ∩ dilate(U, edit_expand)
```

含义：

> 原人物和新人物附近一定使用编辑图 E。

推荐参数：

```text
edit_expand = 8 ~ 32 px
```

如果人物边缘复杂、头发多、脚底阴影明显，可以加大：

```text
edit_expand = 24 ~ 64 px
```

---

## 3. 原图安全背景区 safe_bg

不要直接用：

```text
A - U
```

更稳的是：

```text
safe_bg = A ∩ not dilate(U, edit_expand + transition_width)
```

含义：

> 只有距离原人物和新人物足够远的背景，才 100% 使用原图。

推荐参数：

```text
transition_width = 32 ~ 128 px
```

通常：

| 场景     | edit_expand | transition_width |
| ------ | ----------: | ---------------: |
| 小物体替换  |        8~16 |            24~48 |
| 半身人物替换 |       16~32 |            48~96 |
| 全身人物替换 |       24~48 |           64~128 |
| 脚底阴影明显 |       32~64 |           96~160 |

---

## 4. 过渡区 transition

```text
transition = A - edit_core - safe_bg
```

这个区域不能硬切。它应该通过距离场计算权重。

---

# 三、最终合成权重

定义一个原图权重 `W_O`：

```text
W_O = 1 表示完全使用原图 O
W_O = 0 表示完全使用编辑图 E
```

规则：

```text
A 外部：W_O = 1
safe_bg：W_O = 1
edit_core：W_O = 0
transition：根据距离自然变化
```

最终合成：

```text
Result = O * W_O + E * (1 - W_O)
```

---

# 四、为什么建议用距离场，而不是普通 Gaussian Blur

普通 blur 的问题是：

```text
safe_bg blur 后可能渗透到人物区域
edit_core blur 后也可能污染安全背景
```

尤其人物边缘、头发、透明边缘，会导致重影。

更好的方式是 **distance transform**。

在过渡区里计算：

```text
d_edit = 当前像素到 edit_core 的距离
d_safe = 当前像素到 safe_bg 的距离
```

然后：

```text
W_O = d_edit / (d_edit + d_safe)
```

解释：

| 位置           | d_edit | d_safe |   W_O | 结果  |
| ------------ | -----: | -----: | ----: | --- |
| 靠近 edit_core |      小 |      大 |  接近 0 | 用 E |
| 靠近 safe_bg   |      大 |      小 |  接近 1 | 用 O |
| 中间区域         |     相近 |     相近 | 约 0.5 | 混合  |

这样比单纯 mask blur 稳很多。

# 五、完整节点逻辑

建议节点名：

```text
Smart Object Replace Composite
```

## 输入


# 六、推荐主流程

```text
原图 O
  ↓
手涂遮罩 A
  ↓
裁剪 + inpaint / 替换
  ↓
得到编辑图 E
  ↓
获取 A_P 和 B_P
  ↓
Smart Object Replace Composite
  ↓
最终图
```

关键点：

```text
不要让 E 的整个 A 区域直接覆盖 O
只让 E 在 AP/BP 附近保留
安全背景区强制回贴 O
中间区域做距离场融合
```

# 七、节点内部伪代码

```python
O = original_image
E = edited_image

A  = mask_A
AP = mask_A_P
BP = mask_B_P

# 1. 联合人物/物体遮罩
U = max(AP, BP)

# 2. 编辑核心区
edit_core = A * dilate(U, edit_expand)

# 3. 安全背景区
safe_bg = A * (1 - dilate(U, edit_expand + transition_width))

# 4. 过渡区
transition = A * (1 - edit_core) * (1 - safe_bg)

# 5. 距离场权重
d_edit = distance_to(edit_core)
d_safe = distance_to(safe_bg)

W_inside_A = d_edit / (d_edit + d_safe + 1e-6)

# 强制约束
W_inside_A[edit_core == 1] = 0
W_inside_A[safe_bg == 1] = 1

# A 外部一定使用原图
W_O = ones_like(A)
W_O[A == 1] = W_inside_A[A == 1]

# 6. 可选：对 W_O 做轻微平滑
W_O = blur(W_O, final_blur)

# 7. 再次强约束，避免人物被原图污染
W_O[edit_core == 1] = 0
W_O[safe_bg == 1] = 1
W_O[A == 0] = 1

# 8. 合成
Result = O * W_O + E * (1 - W_O)
```

# 八、颜色匹配处理

即使你安全背景用回原图，`transition` 和 `edit_core` 边缘附近仍可能有色差。

所以建议在合成前对 `E` 做一次背景颜色校正。

参考区域用：

```text
color_ref_mask = safe_bg
```

因为 safe_bg 是原图背景和编辑图背景理论上应该一致的地方。

计算：

```text
O 在 safe_bg 区域的 RGB 均值/方差
E 在 safe_bg 区域的 RGB 均值/方差
```

然后把 E 的背景部分校正到 O 的色调。

但注意：

```text
不要强行改 B_P 内的新人物颜色
```

所以颜色校正应用区域应该是：

```text
color_apply = A ∩ not erode(B_P, protect_radius)
```

也就是：

* 背景区域可以校色；
* 新人物核心区域不校色；
* 新人物边缘可以轻微受影响。

推荐：

```text
protect_radius = 3 ~ 12 px
```

```python
import torch
import numpy as np
import cv2


def to_numpy_mask(mask):
    """
    ComfyUI MASK: [H, W] or [1, H, W]
    return: float32 [H, W], 0~1
    """
    if isinstance(mask, torch.Tensor):
        mask = mask.detach().cpu().float().numpy()

    if mask.ndim == 3:
        mask = mask[0]

    mask = np.clip(mask, 0.0, 1.0).astype(np.float32)
    return mask


def dilate_mask(mask, radius):
    if radius <= 0:
        return mask

    k = radius * 2 + 1
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (k, k))
    out = cv2.dilate(mask.astype(np.float32), kernel)
    return np.clip(out, 0.0, 1.0)


def erode_mask(mask, radius):
    if radius <= 0:
        return mask

    k = radius * 2 + 1
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (k, k))
    out = cv2.erode(mask.astype(np.float32), kernel)
    return np.clip(out, 0.0, 1.0)


def blur_mask(mask, radius):
    if radius <= 0:
        return mask

    k = radius * 2 + 1
    out = cv2.GaussianBlur(mask.astype(np.float32), (k, k), 0)
    return np.clip(out, 0.0, 1.0)


def distance_weight(edit_core, safe_bg, A):
    """
    返回原图权重 W_O:
    edit_core = 1 -> W_O = 0
    safe_bg   = 1 -> W_O = 1
    transition 内用距离场平滑
    """
    edit_bin = (edit_core > 0.5).astype(np.uint8)
    safe_bin = (safe_bg > 0.5).astype(np.uint8)
    A_bin = (A > 0.5).astype(np.uint8)

    # 防止空 mask
    if edit_bin.sum() == 0:
        W = np.ones_like(A, dtype=np.float32)
        return W

    if safe_bin.sum() == 0:
        W = np.ones_like(A, dtype=np.float32)
        W[A_bin == 1] = 0.0
        return W

    # distanceTransform 计算的是到 0 像素的距离
    # 所以这里用 1 - seed，使 seed 区域为 0
    d_edit = cv2.distanceTransform(1 - edit_bin, cv2.DIST_L2, 5)
    d_safe = cv2.distanceTransform(1 - safe_bin, cv2.DIST_L2, 5)

    W_inside = d_edit / (d_edit + d_safe + 1e-6)

    # 强制核心区域
    W_inside[edit_bin == 1] = 0.0
    W_inside[safe_bin == 1] = 1.0

    # A 外全部用原图
    W = np.ones_like(A, dtype=np.float32)
    W[A_bin == 1] = W_inside[A_bin == 1]

    return np.clip(W, 0.0, 1.0)


def match_color_mean_std(O, E, ref_mask, apply_mask, eps=1e-6):
    """
    用 ref_mask 区域估计 O/E 的色差，
    对 E 的 apply_mask 区域做 RGB 均值方差匹配。
    O, E: [H, W, 3], 0~1
    ref_mask/apply_mask: [H, W], 0~1
    """
    ref = ref_mask > 0.5

    if ref.sum() < 64:
        return E

    O_ref = O[ref]
    E_ref = E[ref]

    O_mean = O_ref.mean(axis=0)
    E_mean = E_ref.mean(axis=0)
    O_std = O_ref.std(axis=0)
    E_std = E_ref.std(axis=0)

    E_fixed = (E - E_mean) / (E_std + eps) * O_std + O_mean
    E_fixed = np.clip(E_fixed, 0.0, 1.0)

    a = np.clip(apply_mask, 0.0, 1.0)[..., None]
    out = E * (1.0 - a) + E_fixed * a
    return np.clip(out, 0.0, 1.0)


class SmartObjectReplaceComposite:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "original_image": ("IMAGE",),
                "edited_image": ("IMAGE",),

                "mask_A": ("MASK",),
                "mask_A_P": ("MASK",),
                "mask_B_P": ("MASK",),

                "edit_expand": ("INT", {
                    "default": 24,
                    "min": 0,
                    "max": 256,
                    "step": 1
                }),

                "transition_width": ("INT", {
                    "default": 64,
                    "min": 1,
                    "max": 512,
                    "step": 1
                }),

                "final_blur": ("INT", {
                    "default": 3,
                    "min": 0,
                    "max": 64,
                    "step": 1
                }),

                "color_match": ("BOOLEAN", {
                    "default": True
                }),

                "protect_new_object": ("BOOLEAN", {
                    "default": True
                }),

                "new_object_protect_erode": ("INT", {
                    "default": 6,
                    "min": 0,
                    "max": 64,
                    "step": 1
                }),
            }
        }

    RETURN_TYPES = ("IMAGE", "MASK", "MASK", "MASK", "MASK")
    RETURN_NAMES = (
        "result_image",
        "weight_original",
        "safe_bg_mask",
        "edit_core_mask",
        "transition_mask",
    )

    FUNCTION = "composite"
    CATEGORY = "image/composite"

    def composite(
        self,
        original_image,
        edited_image,
        mask_A,
        mask_A_P,
        mask_B_P,
        edit_expand,
        transition_width,
        final_blur,
        color_match,
        protect_new_object,
        new_object_protect_erode,
    ):
        O_batch = original_image.detach().cpu().float().numpy()
        E_batch = edited_image.detach().cpu().float().numpy()

        B, H, W, C = O_batch.shape

        # MASK 可能是 [H,W]，也可能是 [B,H,W]
        def get_mask_for_batch(mask, i):
            if isinstance(mask, torch.Tensor):
                m = mask.detach().cpu().float().numpy()
            else:
                m = mask

            if m.ndim == 2:
                return np.clip(m, 0.0, 1.0).astype(np.float32)

            if m.ndim == 3:
                if m.shape[0] == B:
                    return np.clip(m[i], 0.0, 1.0).astype(np.float32)
                else:
                    return np.clip(m[0], 0.0, 1.0).astype(np.float32)

            raise ValueError(f"Unsupported mask shape: {m.shape}")

        results = []
        weight_outputs = []
        safe_outputs = []
        edit_outputs = []
        transition_outputs = []

        for i in range(B):
            O = O_batch[i]
            E = E_batch[i]

            A = get_mask_for_batch(mask_A, i)
            AP = get_mask_for_batch(mask_A_P, i)
            BP = get_mask_for_batch(mask_B_P, i)

            # 尺寸保护
            if A.shape != (H, W):
                A = cv2.resize(A, (W, H), interpolation=cv2.INTER_LINEAR)
            if AP.shape != (H, W):
                AP = cv2.resize(AP, (W, H), interpolation=cv2.INTER_LINEAR)
            if BP.shape != (H, W):
                BP = cv2.resize(BP, (W, H), interpolation=cv2.INTER_LINEAR)

            A = np.clip(A, 0.0, 1.0)
            AP = np.clip(AP, 0.0, 1.0)
            BP = np.clip(BP, 0.0, 1.0)

            # 二值化核心逻辑，避免软遮罩脏边
            A_bin = (A > 0.5).astype(np.float32)
            AP_bin = (AP > 0.5).astype(np.float32)
            BP_bin = (BP > 0.5).astype(np.float32)

            # 1. 原人物 + 新人物联合区域
            U = np.maximum(AP_bin, BP_bin)

            # 2. 编辑核心区：AP/BP 附近必须用编辑图
            edit_core = dilate_mask(U, edit_expand)
            edit_core = edit_core * A_bin
            edit_core = np.clip(edit_core, 0.0, 1.0)

            # 3. 安全背景区：远离 AP/BP 的 A 内背景才回贴原图
            safe_radius = edit_expand + transition_width
            unsafe_for_bg = dilate_mask(U, safe_radius)
            safe_bg = A_bin * (1.0 - unsafe_for_bg)
            safe_bg = np.clip(safe_bg, 0.0, 1.0)

            # 4. 距离场生成原图权重
            W_O = distance_weight(edit_core, safe_bg, A_bin)

            # 5. 轻微平滑权重，但要重新钳制核心区域
            if final_blur > 0:
                W_O = blur_mask(W_O, final_blur)

            W_O[edit_core > 0.5] = 0.0
            W_O[safe_bg > 0.5] = 1.0
            W_O[A_bin < 0.5] = 1.0
            W_O = np.clip(W_O, 0.0, 1.0)

            # 6. 可选颜色匹配
            E_used = E.copy()

            if color_match:
                ref_mask = safe_bg

                # 默认不动新人物核心颜色
                if protect_new_object:
                    BP_protect = erode_mask(BP_bin, new_object_protect_erode)
                    color_apply = A_bin * (1.0 - BP_protect)
                else:
                    color_apply = A_bin

                # 颜色校正区域可以稍微平滑
                color_apply = blur_mask(color_apply, 8)
                color_apply = np.clip(color_apply, 0.0, 1.0)

                E_used = match_color_mean_std(
                    O=O,
                    E=E,
                    ref_mask=ref_mask,
                    apply_mask=color_apply,
                )

            # 7. 最终合成
            W3 = W_O[..., None]
            R = O * W3 + E_used * (1.0 - W3)
            R = np.clip(R, 0.0, 1.0).astype(np.float32)

            transition = A_bin * (1.0 - edit_core) * (1.0 - safe_bg)
            transition = np.clip(transition, 0.0, 1.0)

            results.append(R)
            weight_outputs.append(W_O.astype(np.float32))
            safe_outputs.append(safe_bg.astype(np.float32))
            edit_outputs.append(edit_core.astype(np.float32))
            transition_outputs.append(transition.astype(np.float32))

        result_tensor = torch.from_numpy(np.stack(results, axis=0))
        weight_tensor = torch.from_numpy(np.stack(weight_outputs, axis=0))
        safe_tensor = torch.from_numpy(np.stack(safe_outputs, axis=0))
        edit_tensor = torch.from_numpy(np.stack(edit_outputs, axis=0))
        transition_tensor = torch.from_numpy(np.stack(transition_outputs, axis=0))

        return (
            result_tensor,
            weight_tensor,
            safe_tensor,
            edit_tensor,
            transition_tensor,
        )
```

# 十二、最终推荐节点公式

核心公式可以固定为：

```text
U = A_P ∪ B_P

edit_core = A ∩ dilate(U, r1)

safe_bg = A ∩ not dilate(U, r1 + r2)

transition = A - edit_core - safe_bg

W_O =
    1, outside A
    1, in safe_bg
    0, in edit_core
    distance_ramp(edit_core, safe_bg), in transition

Result = O * W_O + E * (1 - W_O)
```

其中：

```text
r1 = edit_expand
r2 = transition_width
```

这比直接用：

```text
A - (A_P + B_P)
```

更稳，因为它保留了人物 / 物体边缘周围的不确定区域，不会把新主体边缘、阴影、接触区域硬切回原图。
